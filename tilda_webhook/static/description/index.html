Tilda (Webhook)

Get leads and orders from Tilda service via webhook technology.


Setup

Read Tilda manual to set up webhook on your website. There is no special settings on the Odoo side.


  • You should set Посылать UTM and Передавать данные по товарам в заказе - массивом on the webhook settings page.
  • Don't forget to set webhook reception service on the required forms.
