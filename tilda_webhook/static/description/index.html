Tilda (Webhook)

Get leads and orders from Tilda service via webhook technology.


Setup

Read Tilda manual to set up webhook on your website.

There is a special security group for Tilda administators in Odoo. It's called Manage Tilda Websites. Only its members can edit tilda website settings.

For all your websites you should do the following:

  1. Go to CRM / Configuration / Tilda Websites.
  2. Set website host. You could see it on webhook settings page too.
  3. Map field names from Tilda forms to Odoo fields. You can find Tilda field name into Content / Input Fields / Variable Name of the form settings.

  • You should set Send UTM and Transfer data for goods in the order - as array on the webhook settings page.
  • Don't forget to set webhook reception service on the required forms.
