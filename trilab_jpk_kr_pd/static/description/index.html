Trilab JPK KR PD (Księgi Rachunkowe)

Moduł do generowania plików JPK KR PD - Księgi Rachunkowe.
Wraz z modułem Trilab JPK Transfer zapewnia pełną obsługę procesu sprawozdawczość JPK KR PD.
Źródłem danych do JPK KR PD są zapisy księgowe z modułu Księgowość.

Mechanizm raportujący działa sposób analogiczny do Raportów Finansowych i umożliwia:

  • podgląd danych,
  • wygenerowanie danych do Excel,
  • wygenerowania pliku HTML,
  • wygenerowanie pliku XML z utworzeniem wysyłki w module JPK Transfer.

Parametrami uruchomieniowymi są:

  • Okres,
  • Opcja statusów zapisów (zaksięgowane lub wraz z niezaksięgowanymi),

UWAGA:

  • Moduł wymaga wcześniejszej instalacji modułu Trilab JPK Base.
  • Opcjonalny moduł Trilab JPK Transfer pozwala na wysłanie plików JPK z poziomu Odoo.
  • Moduł przeznaczony dla wersji Enterprise

Wspiera wersję 18 Odoo.

English Description:

Module for generating JPK KR PD XML files. Together with the Trilab JPK Transfer module provides full support for the JPK KR PD reporting process.

The source data for JPK KR PD are accounting entries from the Accounting module.

The data selection mechanism is flexible and fully parametrised.

The reporting mechanism works in similar to Financial Reports and enables:

  • data preview,
  • generating data for Excel,
  • generate an HTML file,
  • generating an XML file with shipping creation in JPK Transfer models.

The parameters are:

  • Period,
  • Subscription statuses option (posted or together with unposted),

Warning:

  • This module requires prior installation of the Trilab JPK Base module.
  • Optional module Trilab JPK Transfer allows to send JPK files directly from Odoo.
  • Module for Enterprise version.

Supports Odoo version 18.
